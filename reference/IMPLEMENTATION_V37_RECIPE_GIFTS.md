# Chef recipe gifts — v0.37

## Implemented gifts

- Original gift 11003, Barbacoa, multiplies recipe damage by 1.25 when the active cauldron recipe includes attack ingredients.
- Original gift 11004, Doble fritura, multiplies recipe armor by 1.25 when the active recipe includes defense ingredients; the existing 60% mitigation cap remains in force.
- Both records are generated by `scripts/build-gifts.mjs` from the retained Spanish translation data. The `cauldron` requirement limits them to the Chef's first skill or the corresponding effective secondary skill.

## Evidence and limits

- The Spanish and French descriptions identify attack and defense recipes respectively. `reference/REA_COOK_CARDS.md` documents the three ingredient categories and that exact recipe arithmetic is not recovered.
- The 25% multiplier preserves the prototype's local tuning scale; it is not an original server value. The gifts change only cauldron recipe effects, not all Chef attacks.
- No save schema change. Syntax validation is recorded in `HANDOFF.md`; browser QA remains pending.
